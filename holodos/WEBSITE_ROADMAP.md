# War1ouss — план качества и доработок

Актуализировано: 2026-11-14. Здесь статусы **по коду**, а не обещание прохождения визуального или пользовательского теста. Бот `bot_lehaAI`, хранилище SQLite и старые команды должны оставаться работоспособными.

## 1. Визуальный стиль и главная

- [x] Чёрный графитовый / холодный металлический стиль с мягкими цветными бликами; `prefers-reduced-motion`.
- [x] Фоновое изображение белой Monster Energy Ultra только на главной, в верхнем hero.
- [x] Карточки казино, кейсов и дуэлей с полноразмерными файлами WebP, без `object-fit: cover`.
- [x] Кейс с логотипом W на главной и на странице кейсов.
- [x] Разделы рейтингов и реальных последних выигрышей без подставных пользователей.
- [ ] Визуально проверить 320, 375, 390, 768, 1366, 1920 и ultrawide в реальном браузере.
- [ ] Проверить ровность верхнего/нижнего fade, отсутствие полос, размер текста и вертикальных наложений.
- [ ] Проверить скорость загрузки hero на медленной сети и при отключенных внешних шрифтах.

## 2. Хедер и навигация

- [x] Горизонтальный хедер на `/` и боковое меню на внутренних страницах.
- [x] Активный пункт, browser history, Escape, закрытие по нажатию за панелью.
- [ ] Полная проверка клавиатурой и со скринридером; управление фокусом при закрытии меню.
- [ ] Проверить повторные переходы/обновление на каждой вложенной странице и в мобильном браузере.

## 3. Twitch и W

- [x] OAuth вход, серверная сессия, общий SQLite с работающим ботом.
- [x] Реальный баланс и профиль на сайте, периодическое обновление баланса без выдуманных значений.
- [x] Список реальных открытий Холодоса, топ W и топ чата из общей базы.
- [ ] Проверить OAuth login/logout/expiration на реальном аккаунте и браузерах.
- [ ] Проверить обновление баланса после Twitch-команды, покупок и дуэлей одновременно с открытым сайтом.
- [ ] Добавить при необходимости SSE/WebSocket вместо 12-секундного опроса для мгновенной синхронизации.

## 4. Казино и дуэли

- [x] `Холодос` на сайте: серверная выдача результата, три символа, единый двухминутный кулдаун, история.
- [x] Текущие выплаты +5/+20/+400 W; счёт баланса на сервере, UUID запроса.
- [x] Дуэли из сайта через ту же механику, что использует чат; история и ожидающие вызовы.
- [ ] Проверить идемпотентность повторных запросов, анимацию и пользовательские сообщения на ошибках.
- [ ] Нагрузочный тест одновременных действий бота и сайта, а также cooldown/fee/expire дуэлей.
- [ ] Автоматизированные интеграционные тесты с отдельной временной SQLite и фиктивными аккаунтами.

## 5. Кейсы

- [x] Качественная визуальная карточка и отдельная страница без фиктивных цен.
- [x] Нет списаний и случайных наград до согласования экономики.
- [ ] Согласовать кейсы, цены, содержимое, вероятности, ограничения.
- [ ] После согласования: серверный каталог, атомарные списания, генерация наград, история и анимации.
- [ ] Протестировать ограничения, rollback и повторные запросы.

## 6. Магазин VP

- [x] Виртуальные цены: 240 VP — 18 000 W; 475 VP — 35 625 W; 1000 VP — 75 000 W.
- [x] Существующие текстовые команды и ручная обработка; автоматическая выдача VP не включена.
- [ ] Проверить все статусы/ошибки ручных заказов и показывать их пользователю в профиле.
- [ ] Проверить атомарность списания и запрет двойного оформления.

## 7. Надёжность и выпуск

- [x] Один сервис Railway и одно постоянное SQLite-хранилище для сайта и Twitch-бота.
- [x] CSP, HttpOnly/SameSite cookies, CSRF, проверка Origin, серверная валидация на игровых маршрутах.
- [x] Railway `/health` используется как smoke-test при публикации.
- [ ] Сделать и проверить восстановление резервной копии SQLite на изолированной базе (не трогая production).
- [ ] Проверить 404/401/429/500 состояния, задержки сети, отсутствие лишних console errors.
- [ ] Проверить все страницы и запросы в браузере, потому что успешный деплой не доказывает корректную вёрстку.
- [ ] Проверить доступность: цветовой контраст, клавиатура, фокус, 44 px touch targets, Reduced Motion.
- [ ] Запустить отдельные автоматизированные тесты OAuth/действий/транзакций, не обращаясь к боевой базе.

**Не изменять без отдельного запроса:** `!холодос`, `!баланс`, `!топмонет`, `!статмонет`, `!магазин`, `!купить`, `!заказ`, дуэли, W-балансы/историю и команды других ботов.

**Экономика:** W — виртуальная валюта. Не вводить денежные депозиты, вывод средств или автоматическую выдачу VP без отдельного решения.
