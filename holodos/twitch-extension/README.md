# Панель «Холодос» под плеером Twitch

Это Panel Extension размером 318 × 496: ссылки на холодос, кейсы, профиль и живой публичный статус розыгрыша. Вход, участие и управление происходят на сайте. Панель не получает токены пользователей и не расходует баллы Twitch.

1. Открой https://dev.twitch.tv/console/extensions и создай расширение типа Panel.
2. В настройках версии укажи Panel Viewer Path `panel.html`, высоту панели `496`.
3. В Asset Hosting → Files → Upload Version загрузи архив `twitch-panel.zip`. Файлы panel.html, panel.css, panel.js должны быть в корне архива.
4. Разреши `https://holodos-bot-production.up.railway.app` в allowlist для изображений и Connect Sources (публичный статус розыгрыша). Внешние переходы ведут на этот же домен.
5. Включи Hosted Test, добавь свой Twitch-логин в тестировщики и проверь панель на своём канале. Для широкой публикации отправь версию на проверку Twitch, после одобрения установи и активируй в панели под плеером.

Обычное описание канала Twitch не исполняет HTML/JavaScript. Без регистрации Extension можно поставить картинку панели со ссылкой на /widget; живой статус в такой картинке недоступен.

После установки проверь ссылки и обновление регистрации/победителя. Сам архив не активирует расширение на канале: требуется доступ к Twitch Developer Console владельца.
