# Панель «Холодос» под плеером Twitch

Подготовлена панель размером до 318 × 496. Она открывает действующий компактный сайт и разделы кейсов/профиля в отдельной вкладке. Она не выдаёт предметы из iframe, не получает личные балансы и не обходит вход Twitch.

1. В https://dev.twitch.tv/console/extensions создайте расширение типа Panel.
2. Panel Viewer Path: panel.html. Загрузите panel.html и panel.css в Asset Hosting.
3. Разрешите домен holodos-bot-production.up.railway.app для изображений и внешних ссылок по настройкам Twitch.
4. Проверьте Hosted Test на своём канале. Для публичного размещения пройдите проверку Twitch и активируйте расширение в свободном слоте панели.

Это ещё не опубликованное расширение: Client ID и доступ к кабинету расширений не предоставлены. Для действий и личного баланса внутри панели потребуется отдельная серверная проверка Extension JWT и привязка Twitch identity; обычные сессионные cookie сайта для этого не используются.
