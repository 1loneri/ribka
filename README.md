# wariouss

Полный исходный код сайта https://wariouss.qmeow32.chatgpt.site.

Twitch-сообщество: розыгрыши, видео и угадай ранг, профили и уровни, комната сообщества, чат и оверлеи OBS, рыбалка и Twitch-бот.

## Состав

- `app/` — страницы, компоненты, стили и серверные API.
- `lib/` — игровая логика, Twitch, уровни, профили и хранение данных.
- `public/` — изображения, видео, шрифты и лицензии.
- `drizzle/` — SQL-миграции базы данных.
- `scripts/` — установка, сборка и локальный запуск.
- `.openai/hosting.json` — конфигурация существующего проекта Sites и привязок D1/R2.

## Локальная разработка

Нужен Node.js 22.13.0 или новее. Установить зависимости по lock-файлу с помощью `npm run install:ci`, затем запустить `npm run dev`. Сборка: `npm run build`.

Подробности локальных профилей выполнения, D1-миграций и авторизации описаны в [docs/starter-runtime.md](docs/starter-runtime.md).

Проект использует Cloudflare Workers, D1 и R2. Ключи Twitch, ключ нейросети и другие секреты настраиваются отдельно через переменные окружения. Они не включены в репозиторий. Реальная база данных и пользовательские загрузки из R2 также не входят в исходники. Авторизация опубликованного сайта обслуживается Sites; для независимого хостинга потребуется настроить авторизацию и привязки инфраструктуры.
